   [`PR9_STAGED_ACTIVATION.md`](../operations/PR9_STAGED_ACTIVATION.md)を使用する。

   だけを上から順に使用する。
2. このテンプレートには、ケースID、合否、件数、status、reason codeだけを記入する。
3. 会話入力、返答、日記、記憶、メールの内容は、画面で読んで判定するだけにし、
   このファイルへコピーしない。
4. 1項目でも「停止」になったら後続の変更操作を止める。
