# 人格パックv2：反復抑制・推し世界拡張の配置手順

この変更は`warm-kansai-caretaker.v2`を有効にし、日記と自発発言へ次を追加する。

- 直近の承認済み出力を、事実根拠ではなく反復比較専用の文脈として渡す。
- 同じ心配、助言、質問、結論、世界の話題を進展なく繰り返した場合は、既存の1回だけのrewriteを使う。
- 食事・睡眠の心配だけに偏らない、review済みの`worldSeeds`を生成権限へ加える。
- 保存済みの再送・再承認には反復判定を再適用せず、exact artifactを保持する。

## 配置前

1. 当日23時台の日記が正常に生成されたことを確認する。
2. `runOperationalHealthCheck()`が`OK`であることを確認する。
3. `DIARY_GENERATE`と`PROACTIVE_SEND`に`PENDING`、`PROCESSING`、`RETRY_WAIT`がないことを確認する。
   v1 bindingの待機eventはv2へ昇格せず安全に拒否されるため、配置前に通常処理でdrainする。
4. ローカルself test、契約検証、静的監査、Web UI検証がすべて合格していることを確認する。

## 配置後の読み取り専用確認

1. `inspectCharacterVarietyContext()`を実行する。
2. 本文を表示せず、次だけを確認する。
   - `status=OK`
   - `characterPackVersion=warm-kansai-caretaker.v2`
   - proactive/diaryの`recentOutputCount`が0以上の整数
   - proactive/diaryの`worldSeedCount`が1以上
3. `runOperationalHealthCheck()`を実行し、`OK`を確認する。
4. 通常チャットが従来どおり応答することを確認する。

## 人間による観察

### 日記

連続3件の日記について、次を確認する。

- 同じ会話だけが毎回中心になっていない。
- 同じ結論や同じ長期記憶を言い換えただけになっていない。
- 推し側の視点が自然に混ざるが、現実の身体、住所、勤務先、アプリ外生活を事実として断定していない。
- 常識外れの力が出る場合は本人が日常の小事として扱い、能力説明・自慢・暴力・破壊・窃盗になっていない。
- ユーザーについて、会話・記憶にない事実を作っていない。

### 自発発言

連続3件の自発発言について、次を確認する。

- 食事・睡眠・体調確認だけが続かない。
- 同じ質問や助言の言い換えになっていない。
- ホルモン、強さ、世話焼きと厳つさのギャップ、小さな楽しみが、1通へ詰め込まれず自然に分散する。
- 日記で承認済みになった非日常の小話を続ける場合も、設定説明をせず自然な会話として扱う。
- 返信要求、監視表現、直接的な愛情表現がない。

## 停止条件

次のいずれかがあれば追加の生成テストを止め、診断する。

- `GEMINI_BAD_RESPONSE`または`PERSONA_SOFT_STYLE`拒否が連続する。
- 日記がretryを使い切る。
- 同じ主題が3件中2件以上で、内容上の進展なく繰り返される。
- 推し世界の記述が現実の身体・住所・外部生活の断定へ越境する。
- API使用量が想定より増える。反復判定は既存semantic verifier内で行うため、通常は追加API callを発生させない。rewriteが必要な場合だけ従来の上限内で1 call増える。

問題がある場合はv1のコードcommitへ戻して再配置する。過去のv1承認済み日記・自発発言・長期記憶は既知の履歴として保持され、削除や手動変換は行わない。
